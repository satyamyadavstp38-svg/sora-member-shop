# Product, seller, and form planning checklist

The preview includes clearly marked sample sellers, products, prices, and generated sample photos. Prepare these details to replace them.

## For each seller

| Field | What to provide |
|---|---|
| Seller/brand name | The name shoppers should see |
| Seller website URL | The seller’s home or shop URL, starting with `https://` |

## For each product

| Field | What to provide |
|---|---|
| Product name | Exact title or short display title |
| Assigned seller | Choose the seller who owns the listing |
| Category | Home, Tech, Everyday, Workspace, etc. |
| Description | One concise, factual sentence |
| Seller product page | Exact `https://` URL opened by Buy now |
| Image | A product image you own or are authorized to use |
| Price | Current amount and currency; confirm price on seller’s site before launch |
| Display label | Example: “₹2,499” or “See seller for current price” |

## Portal flow in this build

1. Visitors land directly on the shop page and can search/browse categories. Sign-in is required before opening seller checkout links or using account forms/history.
2. Product cards show the assigned seller, price label, and a **Buy now** link to that seller’s own page.
3. After checkout, the signed-in member returns and submits the order form. The selected product/seller are attached automatically. The form records name, account email, order reference, date, amount, required order screenshot, optional delivered-order screenshot, and server timestamp.
4. The member sees their submission in **My orders** and can submit private product-testing feedback tied to that order. It is not posted publicly and has no public star-rating field.
5. Ordinary delivery, return, or refund questions use the separate support form; they are not tied to testing feedback.
6. In **Admin**, add sellers/products, filter order, feedback, support, or catalogue data by seller, and export the currently selected view as CSV.

## Before launch

Publish a privacy notice explaining order references, account email, screenshots, private testing feedback, who can access the information, seller sharing, and retention/deletion. Restrict admin access. Confirm seller/product URLs, image permissions, and prices. Never ask members for seller-site passwords or payment-card details. A normal external link cannot independently confirm that a purchase was completed.
